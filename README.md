# ETF行业轮动模型 V1.0

## 模型逻辑
1. 中期过滤：3个月动量与1个月动量均为正。
2. 核心评分：21日动量 + 5% × 21日IER。
3. ADX：25以上视为趋势较强，20-25进入观察区。
4. IBIAS：默认用收盘价/MA20-1，超过8%只做追高警示，不直接淘汰。
5. MA60：中期趋势确认。
6. MA200：仅作为大周期风险警示，不作为硬性淘汰。
7. 换仓：新标的评分必须比当前持仓高至少0.50个百分点。
8. 全部评分小于0：退出行业轮动池。

## 重要说明
数据抓取层使用东方财富公开行情接口，模型本身不依赖海外指数单独涨跌，而是计算实际场内ETF历史价格。QDII的溢价/折价、IOPV和交易状态应作为下一版执行层单独监控。
